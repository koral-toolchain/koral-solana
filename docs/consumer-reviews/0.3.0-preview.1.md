# Custom-program consumer readiness review

The owner requested four steps: a fresh installation, another domain MVP, a
verified preview and a next-feature decision based on findings.

A new Ubuntu24.04 linux/amd64 container installed JDK17 and official Node22.22.3,
downloaded the immutable public 0.2.0-preview.1 archive and official Agave3.1.10 /
platform-tools1.52 archives, verified checksums, and ran doctor/setup/check/build/
test for Counter55 and payments37. No host SDK/home/dependency cache was mounted.
Docker on macOS arm64 emulates the x64 container; hosted x64 CI is separate.
This proves the recorded isolated setup, not every Linux machine or a physical
new-computer installation. The reproducible script and receipts are retained by
the maintainer; binaries/SDK caches are not source files.

The second independent MVP is an owner-operated inventory quantity ledger with
four fields and five state transitions. Its existing-subset Kotlin compiles to
real SBF and the ABI client drives actual VM transactions. Core zero-initialized
behavior passes 66 assertions, including manual expected transitions, conservation,
permissions and overflow. It is not a renamed payment flow and transfers no funds.

The probe also records a real unmet requirement: generic initialization accepts
invalid application totals before update guards run. Another natural attempt to
share a Kotlin invariant helper is rejected by the current restricted language.
These findings select an opt-in initialization policy as the next feature, with
pure helper functions and SDK onboarding following it. See [ROADMAP.md](../ROADMAP.md)
and [the inventory limitations](../examples/INVENTORY.md).

The 0.3.0-preview.1 candidate groups custom projects, the preview ABI client,
user-owned tests and assertion/syntax/import diagnostics. Publication uses the
exact successful main-CI archive and its SHA-256, without rebuilding it after
selection. Existing published tags and archives remain unchanged. The version
record and release notes must distinguish the current candidate from a published
release; merging this review is not itself publication.

No benchmark was remeasured or performance improvement claimed in this cycle.
Compiler/runtime sources remain unchanged; prior comparison reports retain their
original source/tool/input conditions. No RPC, wallet, token operation, live funds,
Maven/npm publication, website compiler-image update or security audit is implied.
